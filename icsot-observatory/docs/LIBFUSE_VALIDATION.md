## Failures found and repaired

Before live capture, local regression cases exposed and fixed two Git defects: annotated tag peel entries were treated as invalid refs, and a missing reachable blob could pass ref-only verification. The verifier now checks the object graph and independently restores full bundles.

The [first hosted attempt, 40246318334](https://github.com/abhinavagarwal07/ics-ot-collect/actions/runs/40246318334), preserved Git history but correctly failed metadata completeness when GitHub's pagination used `/repositories/48296177/...` instead of `/repos/libfuse/libfuse/...`. Both failed-attempt manifests and their bytes are retained in `evidence/actions/40246318334/`. The pagination fix accepts canonical numeric paths while retaining same-origin, repository-identity and endpoint checks. Acceptance criteria were not relaxed for the successful rerun.

## Remaining implementation boundary

There is no recurring Actions schedule or durable state handoff between hosted jobs. Native XZ archive storage, SQLite collector integration, GitHub Discussions, first-observed commit queries, portable incremental bundles, interval commits in a study Git repository, automatic proof maintenance, RFC 3161 and the monthly admission controller remain unimplemented. The new SQL schema and its tests specify parts of that future implementation; this smoke test does not exercise those features.

Do not describe the pending OTS receipts as verified Bitcoin timestamps. The local receipt check confirmed their manifest digests, parsed proof format, preserved original bytes and pending calendar attestations; it did not verify a Bitcoin block.
